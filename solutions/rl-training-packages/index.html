How it works
  1. 01Brief and sourceA client-style brief and licensed footage. paper-edit-03: three founder interviews, 42 minutes of transcript, cut to 90 seconds.
  2. 02Starting stateA versioned Resolve project or OTIO, EDL or FCPXML timeline, reset before every attempt so each run starts from the same frame.
  3. 03Reference cutA senior editor's cut, with a narrated account of why those quotes, in that order.
  4. 04Automatic checksVerbatim quotes, speaker attribution, timecode, runtime, loudness and delivery spec, checked by script on every attempt.
  5. 05Craft rubricStructure, pace and continuity, scored blind 0–5 by two calibrated editors.
  6. 06Adversarial passAn engineer tries to pass the grader without doing the edit. Every shortcut that scores is closed before release.
  7. 07Difficulty gateA task ships only if frontier agents fail it in at least 70% of attempts and a working editor finds it routine.

Questions
How is this different from a benchmark?

A benchmark measures distance from good work. An environment also ships a reference cut and a reward that can be optimised against. Ours are built so the reward tracks craft, not just compliance.

What stops an agent from gaming the grader?

Automatic checks catch the verifiable failures; a blind, calibrated panel rubric catches the rest. An engineer attempts to pass every grader without doing the work before it ships, and the difficulty gate removes tasks agents can already pass.

Can tasks run in our own harness?

Yes. Starting states ship as Resolve projects and open timeline files, and graders are delivered as code with a documented interface.

Are tasks exclusive?

Non-exclusive by default. A time-limited exclusivity window, typically twelve months, is available; tasks return to the library when it ends.

Who owns the tasks?

Editors and graders assign IP in tasks, reference cuts and narration under an AI-training licence. No client footage is used.

How is work contracted?

Tasks are built against a signed order, with a deposit before work starts.
